## 1. 文件目的

本文件定義 ISO/IEC 27001:2022 權限管理導入的完整驗證與測試方法，涵蓋：

- 權限管理測試案例（單元、整合、滲透）
- 合規性檢查清單（Annex A 對應）
- Wellfit 代碼庫建置與測試指令
- 驗證標準與通過門檻

所有測試皆可重複執行、可追蹤、可稽核。

---

## 2. 測試金字塔（權限管理）

```
        滲透測試（滲透，年度）
       /            \
 整合測試（SSO/MFA/權限，每次部署）
      /              \
 單元測試（權限模型/SoD，每次建置）
```

| 測試層級 | 範圍 | 頻率 | 負責角色 | 驗證工具 |
|---|---|---|---|---|
| 單元測試 | 權限模型、SoD 衝突、RBAC 邏輯 | 每次 `cargo build` | 應用開發 | `cargo test -p <crate> --lib` |
| 整合測試 | SSO、MFA、權限申請核准、JIT 權限 | 每次部署 | 資安 + 開發 | `cargo test -p wellfit_cli --test integration_tests` |
| 滲透測試 | 權限繞過、越權存取、權限提升 | 年度 | 外部安全供應商 | Burp Suite / OWASP ZAP |
| 合規驗證 | Annex A 控制項證據完整性 | 季度 | 內部稽核 | 手動檢查清單 |

## 3. 權限管理測試案例

### 3.1 認證測試

| 測試 ID | 測試項目 | 預期結果 | 測試類型 | 驗證方式 |
|---|---|---|---|---|
| AUTH-001 | 錯誤密碼鎖定機制 | 5 次失敗後鎖定 30 分鐘 | 單元測試 | 模擬連續失敗登入 |
| AUTH-002 | MFA 強制驗證 | 特權帳戶無 MFA 者無法登入 | 整合測試 | 嘗試無 MFA 登入特權帳戶 |
| AUTH-003 | MFA 設定流程 | 使用者可完成 MFA 綁定與驗證 | 整合測試 | 端對端 MFA 綁定流程 |
| AUTH-004 | 會話過期 | 會話超過 8 小時自動失效 | 整合測試 | 模擬逾期會話存取 |

### 3.2 授權測試

| 測試 ID | 測試項目 | 預期結果 | 測試類型 | 驗證方式 |
|---|---|---|---|---|
| AUTHZ-001 | 最小權限原則 | 一般使用者不可存取管理介面 | 單元測試 | 檢查角色權限集 |
| AUTHZ-002 | 職責分離（SoD） | 開發者不可同時擁有生產部署與程式碼變更權限 | 單元測試 | OPA 策略檢查 |
| AUTHZ-003 | 權限繞過測試 | 無權限者直接呼叫 API 返回 403 | 滲透測試 | 直接呼叫受保護端點 |
| AUTHZ-004 | JIT 權限過期 | 臨時特權權限過期後自動失效 | 整合測試 | 申請 JIT 權限並等待過期 |
| AUTHZ-005 | 權限繼承正確 | 子角色繼承父角色權限，不超出範圍 | 單元測試 | 檢查角色繼承邏輯 |

### 3.3 生命週期測試

| 測試 ID | 測試項目 | 預期結果 | 測試類型 | 驗證方式 |
|---|---|---|---|---|
| LIFE-001 | 員工離職帳號停用 | 離職當日 24 小時內所有存取權限撤銷 | 整合測試 | 模擬離職流程，檢查帳號狀態 |
| LIFE-002 | 權限變更核准 | 權限升級需主管核准，無核准記錄者不可生效 | 整合測試 | 嘗試無核准的權限變更 |
| LIFE-003 | 帳號創建審計 | 新帳號創建時產生不可篡改日誌 | 整合測試 | 檢查審計日誌完整性 |
| LIFE-004 | 權限重新認證 | 季度/年度權限重新認證完成率 100% | 合規驗證 | 檢查認證紀錄 |

### 3.4 審計測試

| 測試 ID | 測試項目 | 預期結果 | 測試類型 | 驗證方式 |
|---|---|---|---|---|
| AUDIT-001 | 權限變更日誌完整性 | 所有權限 CRUD 操作皆有不可篡改日誌 | 日誌稽核 | 檢查日誌鏈完整性 |
| AUDIT-002 | 特權操作會議錄製 | 所有特權操作會議皆有錄製檔案 | 整合測試 | 檢查會議錄製存儲 |
| AUDIT-003 | 日誌防篡改 | 日誌檔案無法被未授權使用者修改 | 滲透測試 | 嘗試修改日誌檔案 |

### 3.5 滲透測試

| 測試 ID | 測試項目 | 預期結果 | 測試類型 | 驗證方式 |
|---|---|---|---|---|
| PENTEST-001 | 水平權限提升 | 使用者 A 無法存取使用者 B 的資源 | 滲透測試 | 跨使用者存取測試 |
| PENTEST-002 | 垂直權限提升 | 一般使用者無法存取管理介面 | 滲透測試 | 嘗試存取 /admin 端點 |
| PENTEST-003 | 權限提升漏洞 | 水平與垂直權限提升皆被阻擋 | 滲透測試 | 綜合權限提升場景 |
| PENTEST-004 | JWT 操縱 | 修改 JWT 聲明後無法提升權限 | 滲透測試 | 篡改 JWT 並嘗試存取 |

## 5. Wellfit 代碼庫建置與測試指令

根據 `AGENTS.md`（`C:\Users\stephanie.huang\Desktop\新人訓練\Projects\2026\Dev\Wellfit\AGENTS.md`）：

| 指令 | 說明 | 目標目錄 |
|---|---|---|
| 建置 | `powershell -ExecutionPolicy Bypass -File "Knowledge\tools\dev-env\build.ps1" -Command "build --workspace" -Workspace "." -TargetDir "%LOCALAPPDATA%\Temp\wellfit-target"` | `%LOCALAPPDATA%\Temp\wellfit-target` |
| 測試 | `... -Command "test --workspace"` | 同上 |
| Clippy | `... -Command "clippy --workspace --all-targets -- -D warnings"` | 同上 |
| 單元測試 | `cargo test -p <crate> --lib` | 本地 |
| 整合測試 | `cargo test -p wellfit_cli --test integration_tests` | 本地 |
| MTRIX 手動 | `wellfit mtrix --dir <dir> --batch <id> --db <db>` | 本地 |
| 規格輸出 | `wellfit spec --format markdown` | 本地 |

### 代碼庫品質門檻（合併前）

- [ ] `#![forbid(unsafe_code)]` 全 Crate 生效
- [ ] clippy 零警告：`-D warnings`
- [ ] 所有 public API 必須有文件註解
- [ ] Crate 依賴順序：wellfit_cli → wellfit_mtrix → wellfit_core
- [ ] 單元測試通過率 ≥ 95%
- [ ] 處理時間 < 5s/檔案（`cargo bench`）
- [ ] 錯誤率 < 1%（隔離列比例）
