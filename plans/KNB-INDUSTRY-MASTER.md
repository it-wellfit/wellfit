## 5. 具體實務問題與導入步驟

### 5.1 電商產業

#### 問題 1: 付款卡資料安全（PCI DSS v4.0）
- **問題**：電商平台處理信用卡資料，必須符合 PCI DSS 要求
- **細節**：
  - 12 項 PCI DSS 要求（網路安全、存取控制、監控、測試）
  - SAQ（Self-Assessment Questionnaire）分類
  - QSA（Qualified Security Assessor）審核
- **導入步驟**：
  1. 確定 SAQ 類型（SAQ A, A-EP, B, B-IP, C, C-VT, D, P2PE）
  2. 完成 SAQ 自評
  3. 實施 PCI DSS 控制措施
  4. 通過 QSA 審核（若需要）
  5. 年度重新認證
- **工具**：PCI DSS 合規平台（Secureframe, Drata）
- **驗證**：SAQ 完成率 100%、QSA 審核通過

#### 問題 2: 個人資料保護（GDPR / Taiwan PDPA）
- **問題**：電商平台收集大量個人資料，必須符合隱私法規
- **細節**：
  - 同意管理（Consent Management）
  - 資料主體權利（存取、更正、刪除、可攜帶）
  - 資料外洩通報（72 小時內）
  - 跨境資料傳輸
- **導入步驟**：
  1. 資料盤點與分類
  2. 建立隱私政策與同意機制
  3. 實作資料主體權利請求處理流程
  4. 建立資料外洩應變程序
  5. 定期隱私影響評估（PIA/DPIA）
- **工具**：OneTrust, TrustArc, Cookiebot
- **驗證**：隱私政策完整、同意機制運作、外洩通報流程測試

#### 問題 3: Web 應用程式安全（OWASP Top 10）
- **問題**：電商網站面臨 Web 攻擊威脅
- **細節**：
  - A01: Broken Access Control
  - A02: Cryptographic Failures
  - A03: Injection
  - A04: Insecure Design
  - A05: Security Misconfiguration
  - A06: Vulnerable and Outdated Components
  - A07: Identification and Authentication Failures
  - A08: Software and Data Integrity Failures
  - A09: Security Logging and Monitoring Failures
  - A10: Server-Side Request Forgery (SSRF)
- **導入步驟**：
  1. Web 應用程式安全評估
  2. 實施 OWASP 控制措施
  3. 定期滲透測試
  4. WAF 部署
  5. 安全開發生命週期（SDL）整合
- **工具**：OWASP ZAP, Burp Suite, ModSecurity WAF
- **驗證**：OWASP Top 10 全部通過、滲透測試無高危漏洞

### 5.2 百貨零售產業

#### 問題 1: 供應鏈安全管理（ISO 28000:2022）
- **問題**：百貨零售供應鏈複雜，需管理供應商安全
- **細節**：
  - 供應商評估與審查
  - 物流安全
  - 庫存管理安全
  - 第三方存取管理
- **導入步驟**：
  1. 供應商分類與風險評估
  2. 建立供應商安全要求
  3. 實施供應商審查流程
  4. 監控供應商合規
  5. 定期供應商稽核
- **工具**：供應鏈管理系統、供應商評估平台
- **驗證**：供應商審查完成率 100%、無未審查供應商

#### 問題 2: 客戶資料保護（CRM 安全）
- **問題**：百貨收集大量客戶資料，需保護客戶隱私
- **細節**：
  - 會員資料管理
  - 消費記錄保護
  - 行銷同意管理
  - 資料保留政策
- **導入步驟**：
  1. 客戶資料盤點與分類
  2. 建立資料保留政策
  3. 實作同意管理機制
  4. 定期資料清理
  5. 客戶資料存取控制
- **工具**：CRM 系統、OneTrust
- **驗證**：資料保留政策執行、同意機制運作

#### 問題 3: POS 系統安全
- **問題**：POS 系統是百貨的關鍵基礎設施
- **細節**：
  - POS 終端安全
  - 交易資料保護
  - 庫存同步安全
  - 員工存取控制
- **導入步驟**：
  1. POS 系統安全評估
  2. 實施終端安全控制
  3. 建立交易監控機制
  4. 員工權限管理
  5. 定期安全更新
- **工具**：POS 安全管理、終端保護
- **驗證**：POS 系統安全評估通過、無未授權存取

### 5.3 財會產業

#### 問題 1: 財務內部控制（COSO / SOX 404）
- **問題**：公開企業必須符合 SOX 404 內部控制要求
- **細節**：
  - COSO 5 大要素（控制環境、風險評估、控制活動、資訊與溝通、監控）
  - ITGC（IT 一般控制）：存取控制、變更管理、營運控制
  - 財務報告控制（ITAC）
- **導入步驟**：
  1. 建立內部控制框架（COSO）
  2. 實施 ITGC 控制措施
  3. 建立財務報告控制（ITAC）
  4. 執行內部控制測試
  5. 外部稽核師審核
- **工具**：Workiva, BlackLine, ACL
- **驗證**：內部控制測試通過、外部稽核無重大發現

#### 問題 2: 會計準則合規（IFRS / IAS）
- **問題**：企業必須依 IFRS 編製財務報表
- **細節**：
  - IFRS 15（客戶合約收入）
  - IFRS 16（租賃）
  - IFRS 9（金融工具）
  - IAS 2（存貨）
  - IAS 16（不動產、廠房及設備）
- **導入步驟**：
  1. 評估 IFRS 對企業的影響
  2. 更新會計政策與程序
  3. 調整財務報表格式
  4. 建立 IFRS 合規檢查清單
  5. 定期 IFRS 更新培訓
- **工具**：SAP, Oracle, QuickBooks
- **驗證**：IFRS 合規檢查清單 100% 通過

#### 問題 3: 資料分析與稽核（ISAE 3402 / SOC 1）
- **問題**：服務組織需要提供控制報告給客戶
- **細節**：
  - Type I：特定日期的控制設計
  - Type II：特定期間的控制運作有效性
  - 控制目標與控制活動
  - 獨立稽核師審核
- **導入步驟**：
  1. 確定控制目標
  2. 實施控制活動
  3. 建立控制測試程序
  4. 執行 Type I 審核
  5. 執行 Type II 審核（至少 6 個月）
- **工具**：ACL, IDEA, Workiva
- **驗證**：Type I/II 報告取得

### 5.4 製造業

#### 問題 1: 企業-控制系統整合（ISA-95 / IEC 62264）
- **問題**：製造業需要整合企業系統與控制系統
- **細節**：
  - Level 0-4 架構（設備 → 控制 → 製造執行 → 企業規劃）
  - 資料交換標準
  - 即時資料同步
- **導入步驟**：
  1. 評估現有系統架構
  2. 定義整合需求
  3. 實施資料交換介面
  4. 建立即時監控
  5. 定期整合測試
- **工具**：MES (Siemens Opcenter), ERP (SAP S/4HANA)
- **驗證**：系統整合測試通過、資料同步延遲 < 1s

#### 問題 2: 品質管理系統（ISO 9001:2015）
- **問題**：製造業需要品質管理系統認證
- **細節**：
  - 7 大品質管理原則
  - PDCA 循環
  - 風險導向思維
  - 知識管理
- **導入步驟**：
  1. 建立 QMS 文件
  2. 實施品質控制程序
  3. 建立內部稽核程序
  4. 管理審查
  5. 取得 ISO 9001 認證
- **工具**：QMS 軟體 (ETQ, MasterControl)
- **驗證**：ISO 9001 認證取得

#### 問題 3: 環境管理（ISO 14001:2015）
- **問題**：製造業需管理環境影響
- **細節**：
  - 環境影響評估
  - 法規合規
  - 污染防治
  - 資源使用效率
- **導入步驟**：
  1. 環境影響評估
  2. 建立環境管理程序
  3. 實施環境監控
  4. 法規合規檢查
  5. 取得 ISO 14001 認證
- **工具**：環境管理系統
- **驗證**：ISO 14001 認證取得

- [ ] 安全及資料風險已評估

- [ ] 變更與需求可追溯
- [ ] 文件與 ADR 已同步
- [ ] 監控及回復方案已確認
- [ ] 必要證據已保存
- [ ] 殘餘風險已揭露
